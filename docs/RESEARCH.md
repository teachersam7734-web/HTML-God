# Community workflows added to HTML God

The six repositories supplied by the owner were studied at pinned revisions. The additions are authored production recipes and routing guidance inside HTML-Sensei. No upstream code, model weights, character artwork or external application was bundled by this research pass.

| Source | Integrated value | Where it is used |
|---|---|---|
| [SUPRA-Tex](https://github.com/Supra-3D/supra-tex) | Image-conditioned material preparation, observed/inferred texture boundaries, camera alignment, topology and export checks | [3D workflows](../skills/sensei-3d/references/community-3d-workflows.md) |
| [Motion2MixamoRig](https://github.com/MaxLiu22/Motion2MixamoRig) | Extraction versus retargeting, reusable skeletons, contact, quaternion, IK and collision QA | [3D workflows](../skills/sensei-3d/references/community-3d-workflows.md) |
| [Mesh Avatar Studio](https://github.com/shinshin86/mesh-avatar-studio) | Layered art rigging, fixed-pose review, viewer lifecycle, local tracking and deterministic film boundaries | [3D workflows](../skills/sensei-3d/references/community-3d-workflows.md) |
| [Awesome gamedev agent skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills) | Runtime-specific game routing, cohesive asset families, acceptance criteria and reactive AI | [Game workflows](../skills/sensei-games/references/agent-game-workflows.md) |
| [Huashu Art Motion](https://github.com/alchaincyf/huashu-art-motion) | Layer-level art motion, coordinate manifests, material-driven animation and time-relative transitions | [Art-to-motion workflows](../skills/sensei-motion-graphics/references/art-to-motion-workflows.md) |
| [Framefields](https://github.com/gatewai-dev/framefields) | Deterministic frame clocks, beat-derived timelines and incremental render inspection | [Art-to-motion workflows](../skills/sensei-motion-graphics/references/art-to-motion-workflows.md) |

Read [3D source inspection notes](research/3d-sources.md) and [motion/game source inspection notes](research/motion-game-sources.md) for exact revisions, inspected files, licences and limits. Some model pipelines require external GPU environments or have non-commercial model terms even where application source is permissively licensed. HTML God routes around those restrictions and does not claim those pipelines execute inside an ordinary HTML page.
