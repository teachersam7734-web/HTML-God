# AI Level-Up: what shipped and what was learned

This is a historical case study of the approved project, not a set of mandatory visual choices for every future artefact. The approved HTML was not modified while this skill/manual package was created.

## Brief and evolution

The source was a supplied AI Level-Up manuscript, with a signature and portrait. The first course needed an introductory landing page, Enroll transition, chapter/lesson dashboard, Mega Study Method adaptation, three cumulative flip-card reviews and one 20-question four-option quiz with feedback only at the end.

The later Pro request preserved Standard and added an experience gate, an embedded PDF book with highlights and notes, a Plugin Architecture bonus chapter, six generated portrait variants and a stronger cinematic design across every chapter. Supplied Cognitra and Cyber Ronin references informed composition. A ten-second supplied film became the scroll-controlled book entrance. Subsequent feedback replaced an incoherent cream/green/purple treatment with black, yellow/gold and restrained red, restored visible Review Stop artwork, repaired glass flashcards and embedded the entire supplied soundtrack.

Educational motion expanded from source-inspired SVG graph diagrams into 47 explanations (85 scenarios, 312 steps), then eight selected 3D exhibits (15 scenarios). The user preferred depth and quality to raw scene count. The final request replaced an abstract catalogue with an anatomical brain entrance leading into eight luminous synapses, and added recognisable human/robot actors and detailed objects. The user explicitly allowed independent colours in those exhibits.

## Division of tools

- Native image generation produced conceptual artwork, two broad scene backgrounds, six identity-referenced portraits and the final neural environment.
- Original SVG/HTML produced precise diagrams, labels, recaps and most UI elements.
- Three.js produced live Infinity/chapter sculptures, educational dioramas and the brain/network navigation. GLTFLoader/SkeletonUtils handled the human/robot models.
- Remotion rendered the portrait film and an earlier short course interlude.
- HyperFrames rendered an earlier short course interlude; its registry and seekable composition ideas were researched for later motion. The live neural map is not a HyperFrames render.
- FFmpeg/ffprobe prepared and verified video derivatives. The supplied music was preserved as bytes, not re-synthesised.
- PDF.js rendered the book with a text layer and normalised highlight rectangles.
- Playwright with local Edge tested the actual offline HTML. Python/Node scripts assembled data, preserved files, inspected images/media and recorded evidence.

## Concrete failures and repairs

| Failure / observation | Repair / reusable lesson |
|---|---|
| Pro looked like Standard plus two pages | Redesign page families throughout; add useful premium experiences rather than a small feature list |
| Cream/green shell clashed with purple image remnants | Replace the composition and token roles coherently; inspect actual composites |
| Black Review Stop illustrations | Remove inappropriate multiply blend on transparent artwork; test against final surfaces |
| Card did not reliably flip / reveal | Correct preserved 3D hierarchy and explicit face visibility; test every answer, touch and keyboard |
| Early educational scenes were too abstract | Use recognisable actors, documents, terminals and circuits where they help explain roles |
| Apparent incomplete animation | Separate timed endpoint assertions from visual interpretation; intentional held outcomes need explicit captions |
| GLTF characters vanished or scaled wrongly | Normalise outside animated root; preserve rig structure and inspect frustum/bounds |
| Human Working pose disappeared behind screen | Inspect clip at several times; use a readable Idle stance beside the terminal |
| Generated neural background hidden | Screen-blend the canvas container at the correct stacking level |
| Neural click intercepted/displaced | Decorative layers ignore pointer events; override generic active transform that replaced centring |
| Touch opened immediately instead of preview | Track touch-preview separately from focus selection |
| Desktop geometry persisted after resize | Recreate network layout across aspect breakpoints |
| Mobile final label clipped | Constrain projected labels to the scene bounds and retest all layouts |
| Independent agent could not run | Record workspace-credit failure; perform direct review without claiming independence |

## Source map and preservation

The included implementation reference (`examples/project-source/`) holds the `animations`, `cinema`, `neural`, `reader` and `shared-intro` modules (JS and CSS). The `app`, `pro`, `premium` and `gold` modules, the motion scene sources, video preparation, build logic, scenario data, recap logic and QA scripts stay with the original project. Course content, password, private portraits/signature and supplied films/books/music are not installed as reusable defaults.

The original Standard checkpoint was protected. After a later explicit request authorised the intro in both editions, two marked blocks were inserted. Stripping them restores the original Standard exactly. Pro's core chapters, embedded PDF and music matched their source bytes. This technique preserves a known baseline without blocking authorised narrow changes.

## Evidence and limits

The release passed 74 cinematic checks and 33 neural-navigation checks, including all 15 timed endings, desktop/mobile labels, keyboard/touch, reduced motion, fallbacks and no external network requests. Content coverage checked 29 chapters, 63 lessons and 378 stage templates. Saved earlier reports cover all 48 cards at two widths, quiz scoring, book navigation and the shared intro.

These are Windows/Edge tests and emulated layouts, not a full physical-device lab or formal accessibility certification. Browser storage and WebGL/media support vary. The skill therefore carries the checks and fallback contracts, not a promise that copying the old code makes any new project correct.

## Untaken routes retained for the next project

React Three Fiber/Drei, Babylon.js, PixiJS, Rive, Theatre.js, Lottie, Motion, Lenis, Spline, a hosted application/PWA, native Blender authoring, frame sequences and alternative model libraries were considered or newly researched. The source atlas explains when each becomes appropriate and the remaining verification needed. SWF was rejected for modern browser delivery. No arbitrary 500 MB target was adopted: the user's point was to prioritise quality, not inflate the payload.
